# ChileCombatRec
Repositorio Github para el proyecto final de la asignatura CAPSTONE.

# Tecnologías utilizadas
Frontend: React
Backend: Node.js
Motor de base de datos: MySQL

# Instrucciones para ejecutar el proyecto

Dirigirse a la carpeta "FrontEnd" y iniciar una terminal de cmd con dirección a esa carpeta y ingresar en la terminal "npm run dev", posteriormente,
dirigirse a la carpeta "Backend" y iniciar otra terminal de cmd con dirección dentro de esa carpeta y ingresar en la terminal "node index.js" y se
iniciará el proyecto en su enteridad.
