# ChileCombatRec
Repositorio Github para el proyecto final de la asignatura CAPSTONE.
# Descripción
ChileCombatRec es un sistema web el cúal está destinado para las escuelas o clubes deportivos que imparten deportes de combate, en este sistema les escuelas podrán registrarse y a su vez usarlo para registrar a sus coach y estudiantes, esta información de coach y estudiantes será para uso exclusivo de la escuela que los registra, no podrán ser vistos por escuelas externas, los coach tendrán cuentas personales vinculadas a la escuela y podrán registrar estudiantes y actualizar sus registros, al momento de registrar un estudiante si este ya tiene experiencia o combates anteriores independiente de su disciplina deberán ser registrados, al momento de estar siendo registrados, habrá una opción para ingresar su record de manera rápida. 
Cada escuela tendrá una serie de credenciales exclusiva que representará el “administrador” de la escuela con la que posteriormente podrá borrar si así desea los datos de la escuela o hacer todo tipo de cambios, este administrador tendrá la facultad de designar coaches los cuales tendrán la facultad para leer, registrar, actualizar y eliminar estudiantes de la escuela correspondiente.
Se pedirá rut de los coach encargados de la escuela y de los estudiantes pero no se mostrará posteriormente a otras escuelas al momento de utilizar la opción de ofrecer combates.
El sistema desde la vista de coaches tendrá una opción para buscar oponentes para el estudiante deseado en donde buscará estudiantes de otras escuelas sin mostrar datos sensibles y dará la información de contacto de la escuela del estudiante.

# Tecnologías utilizadas
Frontend: React
Backend: Node.js
Motor de base de datos: MySQL

# Instrucciones para ejecutar el proyecto

Dirigirse a la carpeta "FrontEnd" y iniciar una terminal de cmd con dirección a esa carpeta y ingresar en la terminal "npm run dev", posteriormente,
dirigirse a la carpeta "Backend" y iniciar otra terminal de cmd con dirección dentro de esa carpeta y ingresar en la terminal "node index.js" y se
iniciará el proyecto en su enteridad.
